Set up Lemon Console

Copy config.example.js to config.js, then enter your Guacamole connection IDs and data source. In Guacamole, open Settings → Connections and select a connection. An edit URL ending in /manage/postgresql/c/12 gives data source postgresql and connection ID 12.

Reload this page after saving the file.
